CONFIRMED AND ADDRESSED
1. Agent-chosen local evidence could launch scripts, apps or Terminal profiles.
   All absolute paths and local file URLs now reveal in Finder. There is no safe-
   extension launch allowlist. Remote file URLs and other schemes are rejected.
   Antigravity artifact handoff follows the same non-launching approach.
5. checkpoint could raise StopIteration when an agent's mission disappeared.
   It now reports a useful error before writing any partial checkpoint.
6. Malformed Copilot hook handlers/args could raise AttributeError.
   They now fail with a caught validation error, preserving the existing file.
7. Decision timestamps could precede the request by nearly an hour.
   Requests now carry issuedAt, and replies must fall within that exact lifetime.
   Legacy requests without issue time fail closed. Native replies use click time,
   not the previous observer tick. This does not authenticate a peer writer.
8. Swift could create a permissive state directory/file before the Python bridge.
   New private directories use 0700, files use 0600 from creation through atomic
   replacement. Default owned state can be repaired; shared explicit parent
   directories are not silently chmodded.
9. Output was read after process exit, permitting a pipe-buffer deadlock.
   Both streams and stdin now run off the main actor. Output is continuously
   drained, retained error output is bounded, and the owned process is released.
10. Configurable recursive patterns could scan filesystem root or the whole home.
    Broad wildcard roots (including symlink roots) are rejected. Custom source
    registration takes a single file; disabled sources do not scan. Periodic
    built-in scans remain: this is not an adversarial filesystem/load guarantee.
Claude coverage nit: incomplete coverage now gives Cove's withdrawn/unseen pose.
Claude trust concern: accepted checks and Taste judgments are labelled unsigned
in the main status and inspector. The existing local review writer remains
